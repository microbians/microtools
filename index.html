midiLink

Bluetooth MIDI,
no fuss.

From the menu bar
Your instruments with a check when connected, your own names and icons, and a green light while they play.
Connects by itself
Switch the instrument on and it connects, with a notice; switch it off and it waits for it again, without using your battery.
Works with every app
Each instrument is a MIDI port any music app can use — even the ones macOS’s own Bluetooth MIDI does not pass on.
Routes
The MIDI of one port to another: a Bluetooth keyboard to a USB synth or to an app.

Write your
own tool.

A plugin is a .microplugin folder: a manifest that tells microTools what to show, and the code. microTools draws its settings, its menu, its shortcuts and its notices — you write what it does.

JavaScript plugins

Anyone can write them. An AI too.

They run in their own sandboxed JavaScriptCore context and reach the Mac only through the microtools API, with the permissions you grant each one. Double-click the folder to install it.

// main.js
microtools.register({
  start() { microtools.onShortcut('copy', copy) },
  menu() {
    return [{ title: 'Copy Date',
              symbol: 'doc.on.clipboard',
              action: copy }]
  }
})

Swift plugins

Native, linked against MicroKit.

The official plugins are Swift bundles built on MicroKit, the framework inside microTools. They run with microTools’ own rights, so it only loads Swift plugins signed by microbians.

Every official plugin is published here as a signed, notarized release and listed in catalog/index.json, which microTools reads for Settings › General › More Plugins.
